MINESWEEPER

Decke alle sicheren Felder auf, ohne auf eine Mine zu treten.

Maus: Linksklick deckt auf, Rechtsklick setzt eine Flagge, Doppelklick auf eine Zahl deckt die Nachbarn auf (Chording). Touch: Tippen deckt auf, langes Drücken setzt eine Flagge. Tastatur: ← ↑ → ↓ bewegen, Enter oder Leertaste deckt auf (auf einer Zahl: Chording), F setzt eine Flagge.

Lokale Top 3

Anleitung & Regeln

Ziel: Decke alle Felder ohne Mine auf – so schnell wie möglich.

  • Eine aufgedeckte Zahl sagt, wie viele der 8 Nachbarfelder eine Mine enthalten.
  • Rechtsklick (am Handy: lange drücken) setzt eine Flagge auf vermutete Minen.
  • Der erste Klick ist immer sicher – die Minen werden erst danach verteilt.
  • Doppelklick auf eine Zahl deckt die restlichen Nachbarn auf, wenn genug Flaggen daneben stehen (Chording).
  • Gewonnen ist, wenn alle minenfreien Felder offen sind; die Bestzeit zählt pro Schwierigkeit.
Wie funktioniert der Code?
  • Fairer erster Klick: Die Minen werden erst nach dem ersten Klick verteilt (minenVerteilen). Das angeklickte Feld und seine Nachbarn bleiben minenfrei. So kann niemand im ersten Zug verlieren, und der erste Klick öffnet meist gleich eine Fläche, mit der man weiterrechnen kann. Verteilt wird mit einem „Teil-Mischen“ (Fisher-Yates): Aus der Liste erlaubter Felder werden zufällig so viele nach vorne getauscht, wie es Minen gibt.
  • Flaches Array statt Tabelle: Das Feld ist nur eine Liste. Aus Spalte x und Zeile y wird der Index y * spalten + x, zurück geht es mit % (Rest) und Math.floor (Division). Die Hilfsfunktion nachbarIndizes liefert die bis zu 8 Nachbarn und prüft dabei die Ränder.
  • Flood-Fill mit Stack: Trifft man ein Feld ohne Nachbarminen, öffnen sich automatisch alle angrenzenden Felder. floodFill arbeitet dafür mit einer Schleife und einem Stapel (push/pop) statt mit Rekursion. Eine rekursive Funktion würde bei großen Flächen (30×16 = 480 Felder) sehr tief verschachtelte Aufrufe erzeugen und könnte den Aufrufstapel des Browsers sprengen („Stack Overflow“).
  • Chording: Doppelklick auf eine aufgedeckte Zahl: Stehen rund um das Feld genau so viele Flaggen, wie die Zahl sagt, werden alle übrigen Nachbarn auf einmal aufgedeckt (chordingKandidaten). Das spart viele Klicks, ist aber riskant: Stimmt eine Flagge nicht, trifft man dabei eine Mine.
  • Eine Eingabe-Schaltzentrale: Statt 480 Klick-Handler gibt es nur einen am Feld (Event Delegation). e.target.closest(".zelle") findet die angeklickte Zelle. Rechtsklick läuft über contextmenu, am Handy erkennt ein Timer (setTimeout ca. 400 ms) das lange Drücken und die Pointer Events unterscheiden Maus und Touch.
  • Animierte Wellen: Beim Aufdecken bekommt jede Zelle per style.setProperty("--v", …) eine Verzögerung, die vom Abstand zum Klick abhängt. Das CSS nutzt sie als transition-delay, dadurch läuft die Aufdeck-Welle gestaffelt über das Feld, ganz ohne JavaScript-Animationsschleife.
